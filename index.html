How to use

Basic controls

Left drag
Pan image (move)
Wheel
Zoom in/out
Arrow keys
Alignment adjustment (1px)
Shift + Arrow
Alignment adjustment (10px)
Note: arrow keys are always reserved for alignment

Rectangular crop

Left drag
Select area (selection mode)
Right drag
Pan image (selection mode)
Note: available only in overlay modes (e.g., anaglyph)

3D Pointer

D
Toggle 3D Pointer mode
Mouse move
Move the pointer over the image
Ctrl + Wheel
Adjust 3D Pointer depth
Note: also available in viewer mode

Tips

• Open images by drag and drop
• FIT button auto-zooms to fit the screen
• ZERO button resets alignment
• Image adjustments update in real time while the histogram is shown
• After cropping, use “Remove crop” to revert

Viewer Help

Sphyrnidae
Stereo image viewer

Keyboard Navigation

  • N - Next image
  • P - Previous image
  • L - Toggle file list
  • S - Swap left/right images

Mouse/Touch Navigation

  • Click left 1/6 of the image area - Previous image
  • Click right 1/6 of the image area - Next image
  • Mouse wheel / Touch pinch - Zoom in/out

3D Pointer

Show a depth-adjustable marker to point at features in the stereo image.

  • D / ⊹ - Toggle 3D Pointer mode
  • Move the mouse - Move the pointer over the image
  • Ctrl+Wheel - Adjust 3D Pointer depth

Controls

  • Loop mode - Wrap around to first image when reaching the last image
  • Display mode - Change the 3D display format (anaglyph, interlace, etc.)
